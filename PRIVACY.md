# Privacy Policy — Block Site Chrome

_Last updated: November 10, 2026_

Block Site Chrome ("the extension") is developed by hpscript. This policy explains what data the extension handles.

## Summary

**All data stays on your device.** The extension has no servers, no accounts, no analytics and no advertising. Nothing you do is sent to the developer or to any third party.

## Data the extension stores locally

The following is saved with Chrome's `chrome.storage` API inside your browser profile:

- **Your settings** — your block list, Strict Mode end times, Focus Mode allowlist and preferences.
- **Visit statistics** — for each website domain (for example `github.com`), the number of visits and blocked attempts per hour. Full URLs, page titles and page contents are **not** recorded. Statistics older than 8 days are deleted automatically.

You can turn statistics off at any time (Settings → Activity statistics) and delete them (Settings → Clear statistics). Removing the extension deletes all of its data.

## Website access

The extension needs access to all websites so it can redirect blocked sites to its block page and count visits per domain for your dashboard. It does not read, modify or collect the content of the pages you visit.

## Data sharing

**User data is never sold, transferred or shared with any third party, under any circumstances.**

The extension does not collect user data on any server, so no user data is available to the developer or to anyone else. User data is not used or transferred for any purpose unrelated to the extension's single purpose of blocking distracting websites, and it is never used or transferred to determine creditworthiness or for lending purposes. The extension makes no network requests other than loading its own bundled files.

The use of information by this extension complies with the [Chrome Web Store Developer Program Policies](https://developer.chrome.com/docs/webstore/program-policies/) on user data, including the Limited Use requirements.
